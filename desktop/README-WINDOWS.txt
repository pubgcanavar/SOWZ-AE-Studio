SOWZ AE — Windows x64 preview build

INSTALL
1. Extract this ZIP into a normal folder.
2. Run sowz-ae.exe.
3. Use File > Import > After Effects Project… to select an AEP or AEPX file.
4. Read the import loss report carefully. Cancel leaves the project unchanged; Continue imports the supported content and records the limitations.
5. Use File > Save Project to save the editable native project.

NOTES
- This is an early SOWZ AE build using the pinned EffectCraft engine for the editing UI, media, effects and rendering backend.
- Native projects from this desktop build use .ecproj / .ecprojx. The earlier .sowzae prototype is not yet auto-converted.
- Adobe .aex binaries and commercial third-party plug-ins are not bundled or loaded. Effects without a verified import mapping are listed in the AEP report.
- Keep a backup of your original AEP, footage, fonts and plug-in dependencies.
